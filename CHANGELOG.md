# Smart Mining Dump — Changelog

## v1.0.0

Initial release.

### New Features

- Adds a **"Prefer Dumping"** toggle to every mining tower inspector. When enabled, trucks assigned to that tower will attempt to dump dumpable materials in dumping/leveling designations inside the tower's zone before falling back to storage delivery.
- Provides the `smart_dump` console command as an alternative way to toggle the preference per tower.
- Per-tower preference is persisted with the save.
